# discourse-kuu-theme

京圈（https://kyotooo.com ，京都大学学生的中文论坛）的主题组件「KUU 自定义组件」。叠加在第三方主题 FKB Pro 上，FKB Pro 本身的代码不改。

## 里面有什么

| 文件 | 内容 |
|---|---|
| `common/common.scss` | 评分帖书签、顶部分类筛选、二手帖状态标签、卡片预览一行、隐藏新话题小蓝点、手机上插件表单全屏 |

注册后等待页的倒计时、「重新发送」按钮和提示，2026-10-20 起由京大邮箱插件（discourse-kuu-kyoto-email `23ebf86`）负责，这里不再管。

品牌配色（从 Logo 取样）：藏青 `#0A2D56`、樱花粉 `#ED8690`、浅雾蓝 `#C0D1E4`、米白 `#FCF9F2`，自定义颜色优先用这几个。

## 怎么参与开发

1. 从 `main` 开一个分支，改完推上来，开 PR
2. PR 里写清楚：改了什么、为什么、电脑和手机上的截图
3. `main` 受保护：必须走 PR，David 批准后才能合并
4. 合并后由 David 在论坛后台（外观 → 组件 → KUU 自定义组件 →「检查更新」/「更新」）拉取，**合并不会自动上线**

### 本地预览

- 用 Discourse 官方的 [discourse_theme](https://github.com/discourse/discourse_theme) 命令行，把改动实时同步到**自己的本地开发环境**里预览：`discourse_theme watch .`
- 不要同步到线上论坛
- 改动要在电脑和手机宽度下都看一遍

### 规则

- 只改这个组件，不改 FKB Pro
- 选择器尽量窄，只影响要改的地方；每段 CSS 开头写注释：做什么、为什么、日期
- 不引入外部脚本和字体
- 和插件配合的地方（比如等待页和京大邮箱插件），先看对应插件的 README
